# Security

If you find a security problem in Bill Splitter (for example a way to read or change someone else's bill, payments, slips or photos), please report it privately rather than in a public issue:

**[Report a vulnerability](https://github.com/IsaraApae/billsplitter-th/security/advisories/new)** (GitHub's private reporting, on this repository's Security tab).

Please include what you did, what happened, and a link or bill id from a test bill of your own if it helps. Don't test against other people's bills.

Only the version deployed at https://billsplitter-th.vercel.app (the `main` branch) is supported.
